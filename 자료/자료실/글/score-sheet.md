# 첫 한 건 고르기 점수표
한 줄 요약: 공고 세 개를 점수표로 비교하면, 내게 맞는 첫 한 건이 보입니다.

![표지](score-sheet-cover.png)

## 먼저 알아 두세요

> **영감의 한마디**
> 천 리 길도 한 걸음부터라 했쥬~ 한 걸음에 천 리 갈라믄 다리가 먼저 찢어지는디 말여.

처음부터 큰 상을 노리지 않아도 괜찮아요.
**처음에는 신청서를 끝까지 써 보는 것**이 가장 중요합니다.
달리기도 처음엔 가까운 거리부터 뛰어 보잖아요. 그다음에 먼 거리를 뛰면 훨씬 쉬워요.

작은 사업에 뽑혀 본 기록은 다음 신청서에 쓸 수 있는 **내 이력**이 되고, 심사하는 분에게는 "이 사람은 믿어도 되겠네" 하는 신호가 됩니다.

## 고르는 기준 여섯 가지

| 기준 | 이것을 확인해요 | 쉬운 예 |
|---|---|---|
| 1. 내가 신청할 수 있다 | 자격 조건에 내가 해당되나요? (이게 ×이면 바로 다음 공고로!) | 키 120cm 이상만 타는 놀이기구에 키가 안 되면 못 타요 |
| 2. 경쟁이 적을 것 같다 | 누구와 경쟁하나요? 몇 팀이나 신청할까요? | 전국 달리기 대회보다 우리 반 달리기가 1등 하기 쉬워요 |
| 3. 서류가 단순하다 | 처음인데 써야 할 것이 너무 많지 않나요? | 첫날부터 숙제가 열 장이면 지쳐서 포기하기 쉬워요 |
| 4. 내 작품과 맞다 | 공고문의 사업 목적과 내가 하려는 일이 같은 방향인가요? | 그림 대회에 노래를 내면 안 맞죠 |
| 5. 일정이 넉넉하다 | 신청서를 쓸 시간과 일을 준비할 시간이 충분한가요? | 시험이 내일이면 공부가 안 돼요 |
| 6. 떨어져도 다음이 있다 | 해마다 열리는 사업인가요? | 이번에 못 가도 내년에 또 갈 수 있는 소풍이면 마음이 편해요 |

## 2번이 제일 헷갈려요: 경쟁이 적은지 어떻게 알아요?

![핵심 카드](score-sheet-compete.png)

**경쟁**은 같은 사업에 신청하는 다른 예술인들이에요. 신청하는 사람이 적을수록 뽑힐 가능성이 커지겠죠? 이렇게 따져 보세요.

### 하나. 범위가 얼마나 넓은가요?

| 사업의 범위 | 누구와 경쟁하나요? | 경쟁 |
|---|---|---|
| 전국 | 전국에 있는 예술인 모두 | 많아요 |
| 시·도 | 그 지역에 사는 예술인 | 중간 |
| 구·군·동네 | 우리 동네 예술인 | 적은 편이에요 |

범위가 **좁아질수록** 경쟁하는 사람이 줄어들어요. 그래서 처음에는 내 동네 사업부터 보는 게 좋습니다.

### 둘. 자격 조건은 어떤가요?

| 자격 조건 | 경쟁은 어떨까요? |
|---|---|
| 누구나 신청 가능 | 신청하는 사람이 많아서 경쟁이 **커요.** 자격이 넓다고 좋은 게 아니에요 |
| 청년·여성·장애인처럼 정해진 사람만 | 같은 조건의 사람끼리만 경쟁해요. 예를 들어 청년 사업은 중장년과 안 겨뤄서 좋지만, **청년이 많이 몰릴 수도** 있어요 |
| 조건이 까다로운 사업(여러 자격이 필요) | 해당되는 사람이 적어서 지원하는 사람이 적을 수 있어요. **내가 해당된다면 기회!** 단, 준비할 서류가 많을 수 있어요(3번 확인) |

### 셋. 몇 팀을 뽑고, 돈은 얼마인가요?

- 공고문의 **지원 내용**에서 몇 팀을 뽑는지 보세요.
- 지원 금액이 클수록 사람들이 많이 몰려요.
- 지난해에 몇 팀이 신청하고 몇 팀이 뽑혔는지 알려 주는 곳도 있어요. (기관마다 달라요. 공고문이나 기관 누리집을 확인해 보세요.)

## 점수표

각 칸에 이렇게 표시하세요.
**○** = 맞아요 / **△** = 반쯤 맞아요 / **×** = 아니에요

| 기준 | 공고 A | 공고 B | 공고 C |
|---|---|---|---|
| 공고 이름 | | | |
| 1. 내가 신청할 수 있다 | | | |
| 2. 경쟁이 적을 것 같다 | | | |
| 3. 서류가 단순하다 | | | |
| 4. 내 작품과 맞다 | | | |
| 5. 일정이 넉넉하다 | | | |
| 6. 떨어져도 다음이 있다 | | | |
| ○ 개수 | | | |
| × 개수 | | | |

## 결과 보는 법

- **1번이 ×** → 신청할 수 없는 사업이에요. 바로 다음 공고를 보세요.
- **○가 5개 이상** → 첫 한 건으로 좋아요! 바로 시작하세요.
- **○가 3~4개이고 ×가 1개 이하** → 그 하나만 해결되면 도전해도 좋아요.
- **×가 2개 이상** → 이번에는 쉬고, 다음 공고를 찾아봐요.

## 예시로 해 봅시다 (가상)

**3인조 음악 팀이 고른 공고: 초록구문화재단 '어르신과 함께하는 찾아가는 예술'**

| 기준 | 점수 | 이유 |
|---|---|---|
| 1. 내가 신청할 수 있다 | ○ | 초록구에서 활동하는 예술인이라 신청할 수 있어요 |
| 2. 경쟁이 적을 것 같다 | △ | 전국이 아니라 초록구 팀끼리만 경쟁해요. 그래도 몇 팀이 신청할지는 몰라요 |
| 3. 서류가 단순하다 | ○ | 신청서와 활동 사진 정도만 내면 돼요 |
| 4. 내 작품과 맞다 | ○ | 마침 복지관에서 공연하려던 참이에요 |
| 5. 일정이 넉넉하다 | ○ | 신청 마감까지 한 달이에요 |
| 6. 떨어져도 다음이 있다 | ○ | 해마다 열린다고 적혀 있어요 |

**결과: ○ 다섯 개, △ 한 개! 이 팀의 첫 한 건으로 좋아요.**

## 공고는 어디서 찾나요?

- 검색창에 **[내가 사는 지역 이름] + 문화재단**을 입력해 보세요.
  (예: 초록구에 산다면 '초록구문화재단')
- 구청 누리집의 **'고시·공고' 게시판**도 둘러보세요. 사람들이 잘 안 가서 경쟁이 적을 때가 있어요.
- **"용의 꼬리보다 뱀의 머리"**라는 말이 있어요. 전국 1등들이 모인 곳에서 꼬리가 되기보다, **내 동네에서 머리가 되어 보는** 거예요. 범위가 좁을수록 경쟁이 적으니까요. (사업마다 다르니 공고문에서 꼭 확인하세요.)

## 체크 5줄

- [ ] 공고 세 개를 점수표로 비교해 봤나요?
- [ ] 1번(내가 신청할 수 있다)이 ○인 공고만 남겼나요?
- [ ] 범위와 자격 조건을 보고 경쟁이 적은지 따져 봤나요?
- [ ] 마감일과 내 준비 시간이 맞나요?
- [ ] 이 사업이 내년에도 열리는지 확인했나요?
