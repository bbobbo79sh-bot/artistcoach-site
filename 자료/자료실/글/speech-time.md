# 심사 발표 시간 계산기
한 줄 요약: 대본을 붙여 넣으면 발표 시간이 나오고, 제한 시간에 맞는지 바로 알려 드려요.

## 이럴 때 쓰세요

대면 심사나 발표 심사에는 시간 제한이 있어요. 보통 5분, 10분, 15분 안팎이에요.
대본을 다 쓰고 나서 소리 내어 읽어 보면 시간이 넘는 일이 많아요.
그때마다 처음부터 다시 줄이면 힘들어요. 이 계산기로 **쓰는 동안 미리 재 보세요.**

아래 계산기에 대본을 붙여 넣으면 이런 것을 알려 줘요.

| 알려 주는 것 | 설명 |
|---|---|
| **글자 수·단어 수** | 공백 포함, 공백 제외, 단어 수, 바이트 |
| **예상 발표 시간** | 말하는 속도에 맞춰 분·초로 계산해요 |
| **제한 시간과 비교** | 몇 초 넘는지, 몇 글자를 줄이면 되는지 알려 줘요 |
| **슬라이드 시간** | 슬라이드를 넘기고 영상을 보여 주는 시간도 더해요 |

## 쓰는 순서

1. 대본을 붙여 넣어요.
2. 말하는 속도를 골라요. 잘 모르겠으면 **보통**으로 두세요.
3. 슬라이드를 쓰면 장수와 넘기는 시간을 넣어요.
4. 심사 발표 시간(예: 10분)을 눌러 보세요. 맞는지, 줄일 글자 수가 나와요.

더 정확하게 재고 싶으면 **내 말 속도 재기**를 쓰세요. 스톱워치를 켜고 대본 첫 부분을 20초쯤 소리 내어 읽은 뒤, 읽은 만큼 붙여 넣으면 내 속도로 계산해 줘요.

## 발표 시간 맞추는 요령

- 발표 시간을 **꽉 채우지 마세요.** 제한 시간보다 20~30초 짧게 맞추면, 긴장해서 빨리 말하거나 잠깐 멈춰도 안전해요.
- 줄일 때는 **설명을 줄이고, 핵심 숫자와 이름은 남기세요.**
- 슬라이드는 한 장에 20~40초 정도로 잡으면 무리가 없어요.
- 마지막에는 꼭 **소리 내어 한 번** 재 보세요. 계산기는 평균이라서 내 말투와 다를 수 있어요.
