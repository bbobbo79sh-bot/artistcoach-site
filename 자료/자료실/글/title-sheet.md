# 사업명 짓기 워크시트
한 줄 요약: 심사위원이 제일 먼저 읽는 글, 사업명. 빈칸 네 개를 채우면 후보가 나옵니다.

![표지](title-sheet-cover.png)

## 먼저 알아 두세요

![이해하고 시작 vs 의문만 품고 시작](title-sheet-compare.png)

**사업명은 심사위원이 신청서에서 제일 먼저 읽는 글**입니다.
그래서 이 한 줄이 아주 중요해요. 사업명을 읽은 심사위원은 둘 중 하나가 됩니다.

| 사업명을 읽고 나서 | 신청서를 읽는 마음 |
|---|---|
| **"아, 이런 사업이구나"** 하고 이해했어요 | 이해한 채로 읽으니 뒤의 내용이 쉽게 들어와요 |
| **"이게 무슨 사업이지?"** 의문만 생겼어요 | 의문을 품은 채로 읽으니 계속 갸웃거리게 돼요 |

책 표지나 가게 간판과 같아요. 간판만 보고도 무슨 가게인지 알면 마음 편히 들어가지만, 무슨 가게인지 모르면 문 앞에서 망설이죠.
**심사위원이 이해하고 시작하게 하느냐, 의문을 품고 시작하게 하느냐**는 아주 큰 차이예요.

## 사업명은 작품명이 아니에요

- **작품명**: 작품에 붙인 멋진 이름. 예) 「어둠 속의 콘서트」
- **사업명**: 이 일이 **누구를 위해 무엇을 하는지**까지 알려 주는 이름.
  예) 장애예술인과 함께하는 장애인식개선 공연 「어둠 속의 콘서트」

**쉬운 비교**: 책 표지에 「해리포터」라고만 쓰면 이름은 멋지지만 어떤 이야기인지 몰라요.
"마법 학교에 간 소년의 모험 「해리포터」"라고 쓰면 무슨 이야기인지 바로 알 수 있죠.
사업명도 그렇게 지어요.

## 1단계. 사업 개요를 한 줄로

내 일이 어떤 일인지, 한 문장으로 먼저 말해 보세요.

> 예) 5년 동안 함께 연주한 세 사람이, 공연장에 오기 힘든 어르신께, 복지관으로 찾아가 노래를 들려 드립니다.

| 누가 | 누구에게 | 무엇을 | 어떻게 |
|---|---|---|---|
| | | | |

## 2단계. 네 가지 재료 채우기

사업명에는 네 가지 재료가 들어가면 좋아요.

| 재료 | 이것을 생각해요 | 쉬운 예 | 내 답 |
|---|---|---|---|
| 1. 누구에게 | 누구를 위한 일인가요? | 어르신께, 아이들과, 동네 주민과 | |
| 2. 어떻게 | 어떤 방법인가요? | 찾아가는, 함께 만드는, 쉽게 배우는 | |
| 3. 핵심 활동 | 무엇을 하나요? | 작은 음악회, 그림 수업, 전시 | |
| 4. 작품 이름 | 이 일만의 이름이나 한마디는? | '봄결, 노래가 온다' | |

## 3단계. 이어서 후보 만들기

네 재료를 순서대로 이으면 사업명이 됩니다. 후보를 세 개 만들어 보세요.
길이는 **30자 안팎**이 좋아요. 너무 길면 읽다가 숨이 차요.

| 후보 | 사업명 | 글자 수 |
|---|---|---|
| 1 | | |
| 2 | | |
| 3 | | |

## 4단계. 점검하기

- [ ] 작품 이름만 쓰지 않고, 누구에게 무엇을 하는지도 들어갔나요?
- [ ] 네 가지 재료가 들어갔나요?
- [ ] 30자 안팎인가요?
- [ ] 심사위원이 읽고 "아, 이런 사업이구나" 하고 이해할까요?
- [ ] 소리 내어 읽어 봤나요? (입에 안 붙으면 읽는 사람 귀에도 안 붙어요)
- [ ] 공고문의 핵심 단어(예: 어르신, 문화 즐기기)가 들어갔나요?

## 예시로 해 봅시다 (가상)

3인조 음악 팀 '봄결 트리오'가 어르신 복지관 공연을 준비해요.

| 재료 | 답 |
|---|---|
| 1. 누구에게 | 어르신께 |
| 2. 어떻게 | 찾아가는 |
| 3. 핵심 활동 | 작은 음악회 |
| 4. 작품 이름 | '봄결, 노래가 온다' |

**완성된 사업명**
> **어르신께 찾아가는 작은 음악회 '봄결, 노래가 온다'** (29자)

심사위원이 이 한 줄만 읽어도 **누구에게, 어떻게, 무엇을 하는지** 알 수 있죠?

## AI에게 도움 청하기

```
아래는 제 사업이 어떤 일인지 정리한 글입니다. [1단계 내용]
사업명 후보를 10개 만들어 주세요.
누구에게, 어떤 방법으로, 무엇을 하는지, 작품 이름이 모두 들어가게 하고, 30자 안팎으로 해 주세요.
처음 읽는 사람도 무슨 일인지 바로 알 수 있는 쉬운 말로 지어 주세요.
공고문의 핵심 단어는 [단어]입니다. 이 단어가 자연스럽게 들어가면 좋아요.
```

**마음에 드는 게 없으면 조각하세요**
```
[번호]번 이름이 마음에 들어요. 그 느낌으로 10개 더 만들어 주세요.
```
```
[단어]는 빼고, [단어]는 꼭 넣어서 10개 더 만들어 주세요.
```

**꼭 하세요**: AI가 거짓말이나 과장을 하진 않았는지 꼭 체크하세요!! 후보 중 2~3개를 골라 소리 내어 읽어 보고, **내 입에 붙는 것**으로 최종 선택하세요.

> **영감의 한마디**
> 이름이 길믄 심사위원이 숨차유~ 서른 자만 넘기지 말어유.
