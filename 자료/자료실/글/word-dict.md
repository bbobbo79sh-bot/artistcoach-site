# 공고문 단어 해석 사전
한 줄 요약: 공고문의 어려운 행정 용어를, 예술인 입장에서 쉽게 풀어 쓴 사전이에요.

![표지](word-dict-cover.png)

## 먼저 알아 두세요

지원사업 공고문을 읽다가 "무슨 말인지 모르겠다" 싶었다면, 이상한 게 아니에요.
공고문은 공공기관이 쓰는 **행정 용어**로 쓰여 있어서, 예술을 하는 분들께는 낯선 게 당연해요.

그래서 영감이 공고문을 여러 개 읽으면서 **자주 나오는 단어를 예술인 입장에서 쉽게** 풀어 썼어요.
국어사전과는 조금 달라요. "공고문에서 이 말이 나오면 이런 뜻이구나" 하고 이해하는 용도예요.

> **영감의 한마디**
> 행정 용어가 어색한 건 자네 탓이 아니여~ 말이 어려운 거지. 몇 번 보믄 금방 익숙해져유.

## 이렇게 쓰세요

아래 상자에서 **궁금한 단어를 쳐서** 찾거나, **묶음(돈과 예산, 서류와 절차, 사람과 단체, 성격과 방향, 지원 자격)**을 눌러서 훑어보세요.
공고문을 읽다가 모르는 말이 나오면 이 페이지를 열어 두고 하나씩 찾아보면 돼요.

## 헷갈리기 쉬운 짝꿍 4개

| 짝 | 쉬운 구분 |
|---|---|
| **주최 / 주관** | 주최는 행사를 여는 **주인**, 주관은 그 일을 **맡아서 운영**하는 쪽이에요 |
| **지향 / 지양** | 지향은 "그쪽으로 **가겠다**", 지양은 "그건 **하지 않겠다**"예요 |
| **영리 / 비영리** | 영리는 **돈 버는 게 목적**, 비영리는 번 돈을 나눠 갖지 않고 **단체의 일에 다시 쓰는 것**이에요 |
| **지원금 / 자부담** | 지원금은 **지원사업에서 받는 돈**, 자부담은 **내가 보태는 돈**이에요 |

## 사전에 없는 단어를 만났다면

AI에게 이렇게 물어보세요. 공고문의 문장을 그대로 붙여 넣으면 더 정확해요.

```
아래는 예술지원사업 공고문의 일부입니다. [공고문 문장 붙여넣기]
이 문장에서 어려운 단어를 모두 찾아서, 예술을 하는 사람이 이해할 수 있게 쉬운 말로 풀어 주세요.
각 단어는 한 줄로, 예를 하나씩 들어 주세요.
```

**꼭 하세요**: AI가 거짓말을 하진 않았는지 꼭 체크하세요!! 돈, 자격, 마감처럼 중요한 내용은 공고 원문이나 담당자 문의로 한 번 더 확인하세요.
