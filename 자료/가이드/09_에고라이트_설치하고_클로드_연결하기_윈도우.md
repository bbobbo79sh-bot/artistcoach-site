# 에고 라이트(ego lite) 설치하고 클로드와 연결하기 — 윈도우 컴퓨터 편
한 줄 요약: 에고 라이트는 클로드가 직접 쓸 수 있는 전용 인터넷 창이에요. 설치하고 한 번만 확인해 두면, 클로드에게 "이 사이트 열어서 확인해 줘" 하고 맡길 수 있습니다.

> 2026년 11월 기준 화면입니다. 에고 라이트는 아직 **베타(시험판)** 라서 화면과 단추 이름이 바뀔 수 있어요. 그래도 흐름은 같으니 천천히 따라 오세요.

## 에고 라이트가 뭐예요?

클로드에게 "이 공고 사이트 열어서 마감일만 정리해 줘"처럼 말하면, 클로드가 **에고 라이트 안에서** 인터넷 창을 열고, 읽고, 눌러 가며 일을 해 줍니다. 내 눈앞의 화면에서 하는 일이라 어디를 보고 있는지 직접 볼 수 있어요.

- 사용은 **무료**이고, 에고 라이트에 따로 가입하거나 로그인할 필요가 없습니다. (클로드 계정은 따로 있어야 해요.)
- 클로드와의 연결은 **설치하는 중에 자동으로** 됩니다. 설정 파일을 만들거나 열쇠(키)를 붙여 넣는 일은 없어요.

## 시작하기 전에

- 컴퓨터는 **윈도우(Windows)** 기준입니다.
- **클로드 앱이 이미 깔려 있고 로그인돼 있어야** 해요. 아직이면 먼저 「클로드 설치하기 — 윈도우 컴퓨터 편」을 따라 해 주세요.
- 클로드 앱 맨 위에 **Code(코드)** 칸이 보여야 합니다. 안 보이면 앱 버전이나 계정 요금제 때문일 수 있으니 클로드 사이트의 안내를 확인하세요.
- 20분 안팎으로 걸립니다. 서두르지 않으셔도 돼요.
- 꼭 **공식 사이트**에서만 받으세요.

## 1단계. 에고 라이트 사이트로 가기

인터넷 창 맨 위 긴 칸에 `lite.ego.app/download` 라고 쓰고 키보드의 **Enter(엔터)** 를 한 번 누르세요.

## 2단계. Windows 단추 누르기

![다운로드 화면에서 Windows (beta) 단추 누르기](ego-install-1.png)

화면에 **macOS** 단추와 **Windows (beta)** 단추가 나란히 있어요. **Windows (beta)** 를 한 번 누릅니다. 받아지는 데 잠깐 걸릴 수 있어요.

- 화면에 맥(Mac) 컴퓨터 그림이 보여도 걱정 마세요. 단추만 Windows를 누르면 됩니다.
- 화면 오른쪽 위에 "표시 언어를 한국어로 변경할까요?" 같은 상자가 뜨면 **"한국어로 표시"** 를 눌러도 됩니다.
- 윈도우에서는 아직 **베타(시험판)** 라서 가끔 불편한 점이 있을 수 있어요.

## 3단계. 받은 파일 두 번 누르기

받은 설치 파일을 **마우스 왼쪽 단추로 빠르게 두 번** 누르세요. 파일은 보통 '다운로드' 폴더에 있고, 인터넷 창에 나오는 다운로드 표시에서 눌러도 됩니다. (찾기 어려우면 키보드의 **윈도우 키**를 누르고 `다운로드` 라고 쓴 뒤 나오는 폴더를 누르세요.)

- 파란 창에 **"Windows의 PC 보호"** 같은 안내가 뜨면: **"추가 정보"** 를 누르고, 이어서 나오는 **"실행"** 을 누르세요. 내가 방금 공식 사이트에서 직접 받은 파일일 때만 그렇게 하세요.
- "이 앱이 디바이스를 변경하도록 허용하시겠습니까?" 같은 창이 뜨면 역시 내가 방금 받은 파일일 때만 **"예"** 를 누르세요.

## 4단계. 화면 안내 따라 설치하고 에고 라이트 열기

화면에 나오는 안내를 따라 가며 끝까지 진행하면 **에고 라이트가 열립니다.** (안 열리면 윈도우 키를 누르고 `ego` 라고 쓴 뒤 나오는 것을 누르세요.)

## 5단계. 처음 설정 — 다른 인터넷 창의 정보를 가져올까요?

에고 라이트가 처음 열리면 **"Import data to ego(lite)"** (에고 라이트로 정보 가져오기) 화면이 나올 수 있어요. 지금 쓰는 인터넷 창(엣지·크롬)의 즐겨찾기와 **로그인 정보**를 옮겨 올지 묻는 화면입니다.

- **가져오면**: 이미 로그인해 둔 사이트를 에고 라이트에서도 바로 쓸 수 있어 편해요. 원래 쓰던 인터넷 창은 그대로 남고, 두 창은 이후에 서로 맞춰지지 않습니다.
- **가져오지 않으면**: 로그인이 필요한 사이트는 그때그때 내가 직접 로그인하면 됩니다. 나중에 에고 라이트의 **설정 → Import data** 에서 다시 가져올 수 있어요.

저는 처음에는 **가져오지 않고 시작하는 것**을 권해요. 가져오면 클로드가 내 로그인 상태로 사이트를 열 수 있게 되기 때문이에요. 은행·결제 사이트에 로그인한 인터넷 창이라면 더욱 가져오지 마세요.

- 가져오기로 했다면: 화면에 나온 인터넷 창(엣지 또는 크롬)과 내 프로필을 고르고, 가져올 내용을 눈으로 확인한 뒤 확인을 누릅니다. 윈도우가 묻는 창이 뜨면 읽고 진행하세요.

## 6단계. 클로드에 연결됐는지 확인하기

설치가 끝나면 에고 라이트가 클로드 쪽에 **"ego-browser"** 라는 기능을 자동으로 넣어 둡니다. 눈으로 확인해 볼게요.

1. **클로드 앱을 열어 주세요.** (에고 라이트 설치 때 클로드 앱이 켜져 있었다면, 앱을 한 번 **닫았다가 다시 여세요.**)
2. 앱 맨 위의 **Code(코드)** 를 누르고, 내 컴퓨터에서 하는 **새 작업(로컬 세션)** 을 시작하세요. (화면 모양은 앱 버전에 따라 조금 달라요.)
3. 글 쓰는 칸에 `/ego` 까지 쓰면 아래에 **ego-browser** 가 나타납니다. 보이면 연결된 거예요.

- **Cowork(코워크)** 칸이 아니라 **Code(코드)** 칸이어야 합니다. Cowork 쪽에는 이 기능이 나타나지 않아요.

## 7단계. 첫 번째 시험해 보기

글 쓰는 칸에 아래 글을 그대로 붙여 넣거나 쓰고 **Enter(엔터)** 를 누르세요.

`ego-browser로 https://example.com 을 에고 라이트에서 열어 줘. 실제 주소와 페이지 제목을 알려 줘. 다른 브라우저는 쓰지 마.`

- 클로드가 에고 라이트에서 사이트를 열고, 주소와 제목을 알려 주면 **성공**입니다. 수고하셨어요!
- 클로드가 "이 작업을 해도 될까요?" 하고 물으면, **무슨 일을 하려는지 읽고** 괜찮을 때만 허용하세요.
- 에고 라이트에서 열리는 창은 클로드가 하는 일을 눈으로 볼 수 있는 창이에요. 작업 중에 에고 라이트로 넘어가 보시면 됩니다.

## 지켜 주세요

- **비밀번호와 인증 번호는 클로드 대화창에 쓰지 마세요.** 로그인이 필요하면 에고 라이트 창에서 **내가 직접** 입력하세요. 입력한 뒤 "계속해 줘" 하고 말하면 됩니다.
- **결제, 삭제, 메일·메시지 보내기**처럼 되돌리기 어려운 일은 클로드에게 맡기기 전에 내가 한 번 더 확인하세요.
- 처음에는 "열어서 **읽기만** 해 줘"처럼 읽는 일부터 시켜 보세요.

## 막힐 때는

- **6단계에서 `ego-browser`가 안 보이면:** 지금 **Code(코드)** 칸의 내 컴퓨터(로컬) 작업인지 확인하세요. 에고 라이트 설치가 끝났을 때 클로드 앱이 켜져 있었다면 **앱을 껐다가 다시** 열고 확인하세요.
- **클로드가 에고 라이트를 못 연다고 하면:** 에고 라이트가 **같은 컴퓨터**에 설치돼 있는지 확인하고, 클로드가 허락을 묻는 창이 떴는지 보세요. 허락 창이 있으면 읽고 진행한 뒤 다시 시켜 보세요.
- **시험 중에 로그인 화면이 나오면:** 에고 라이트 창에서 내가 직접 로그인한 뒤 클로드에게 "계속해 줘"라고 하세요.
- **"한도 초과", "인증 오류" 같은 글이 먼저 나오면:** 에고 라이트 문제가 아니라 클로드 계정·이용량 쪽 문제일 수 있어요. 클로드 사이트의 안내를 확인하세요.
- **어디서 막혔는지 모르겠으면:** 화면을 사진으로 찍어 두었다가 아티스트 코치 문의 게시판에 올려 주세요. (계정 이름이나 대화 목록이 보이면 가리고 올려 주세요.)
