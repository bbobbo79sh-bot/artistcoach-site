# 에고 라이트(ego lite) 설치하고 클로드와 연결하기 — 윈도우 컴퓨터 편
한 줄 요약: 에고 라이트는 클로드가 직접 쓸 수 있는 전용 인터넷 창이에요. 컴퓨터를 처음 써 보시는 분도 따라 할 수 있게, 한 장에 한 가지씩만 보여 드릴게요. 설치하고 연결됐는지 한 번만 확인해 두면, 클로드에게 "이 사이트 열어서 확인해 줘" 하고 맡길 수 있습니다.

> 2026년 11월 기준 화면입니다. 에고 라이트는 아직 **베타(시험판)** 라서 화면과 단추 이름이 바뀔 수 있어요. 그래도 흐름은 같으니 천천히 따라 오세요.

## 에고 라이트가 뭐예요?

클로드에게 "이 공고 사이트 열어서 마감일만 정리해 줘"처럼 말하면, 클로드가 **에고 라이트 안에서** 인터넷 창을 열고, 읽고, 눌러 가며 일을 해 줍니다. 내 눈앞의 화면에서 하는 일이라 어디를 보고 있는지 직접 볼 수 있어요.

- 사용은 **무료**이고, 에고 라이트에 따로 가입하거나 로그인할 필요가 없습니다. (클로드 계정은 따로 있어야 해요.)
- 클로드와의 연결은 **설치하는 중에 저절로** 되는 경우가 많아요. 설정 파일을 만들거나 열쇠(키)를 붙여 넣는 일은 없습니다. 아래 8~9단계는 **연결됐는지 눈으로 확인**하는 단계예요.
- 클로드 **앱의 Code(코드) 칸**에서 쓰는 방법이에요. 인터넷의 클로드 채팅창(claude.ai)에서는 쓸 수 없습니다.

## 클로드와는 어떻게 연결되나요?

에고 라이트는 클로드의 **플러그인이나 커넥터를 따로 켜는 방식이 아니에요.** 설치할 때 에고 라이트가 클로드가 읽는 **'사용 설명서(스킬)'** 한 권을 컴퓨터 안 클로드 폴더에 **저절로 넣어 둡니다.** 이름은 **ego-browser** 예요. 클로드가 이 설명서를 읽고 "아, 에고 라이트를 이렇게 쓰면 되는구나" 하고 알게 되는 거예요.

- 그래서 **대부분의 컴퓨터에서는 내가 따로 연결할 일이 없어요.** 설치하고 처음 설정만 끝내면 됩니다. 다만 **컴퓨터에 따라 저절로 안 들어가는 경우도 있어서**, 그럴 때는 아래 「연결이 안 보일 때」에서 직접 넣는 방법을 알려 드려요.
- 대신 **클로드 앱의 Code(코드) 칸에서만** 이 설명서가 보여요. 8~9단계에서 눈으로 확인합니다.
- 에고 라이트를 새 버전으로 고쳐 깔면 이 설명서도 같이 새것으로 바뀌어요.

## 시작하기 전에

- 컴퓨터는 **윈도우(Windows)** 컴퓨터를 기준으로 설명합니다.
- **클로드 앱이 이미 깔려 있고 로그인돼 있어야** 해요. 아직이면 먼저 「클로드 설치하기 — 윈도우 컴퓨터 편」을 따라 해 주세요.
- 클로드 앱 맨 위에 **Code(코드)** 칸이 보여야 합니다. 안 보이면 앱 버전이나 계정 요금제 때문일 수 있으니 클로드 사이트의 안내를 확인하세요.
- 20분 안팎으로 걸립니다. 서두르지 않으셔도 됩니다.
- 꼭 **공식 사이트**에서만 받으세요. 비슷한 이름의 다른 사이트에서 받으면 위험할 수 있어요.

## 1단계. 인터넷 창 열기

인터넷을 보는 창을 엽니다. **엣지(Edge)** 나 **크롬(Chrome)** 중 아무거나 쓰면 됩니다.

- 바탕화면이나 화면 맨 아래 줄에 **Edge(엣지)** 나 **Chrome(크롬)** 그림이 보이면 **한 번 누르세요.** 인터넷 창이 열립니다.
- 안 보이면: 키보드의 **윈도우 키**를 누르고 영어로 `edge` 라고 쓰세요. 맨 위에 나오는 것을 누르면 됩니다. (윈도우 컴퓨터에는 엣지가 처음부터 들어 있어요.)

## 2단계. 인터넷 창 맨 위 칸에 주소 쓰기

![인터넷 창에서 주소 쓰는 칸 찾기](claude-install-0a.png)

인터넷 창이 열리면 **맨 위쪽 줄**에 **길쭉한 칸**이 있어요. 이 칸이 **주소 칸**입니다.

- 화면 한가운데에도 검색 칸이 있을 수 있어요. 그 칸이 **아니라** 맨 위 줄의 긴 칸입니다.
- 주소 칸을 **한 번 누르면** 안의 글자가 파랗게 바뀌어요. 그대로 쓰면 됩니다.

![주소를 쓰고 엔터 누르기](ego-install-0.png)

위 칸에 `lite.ego.app/download` 라고 쓰고 키보드의 **Enter(엔터)** 를 한 번 누르세요.

## 3단계. Windows 단추 누르기

![다운로드 화면에서 Windows (beta) 단추 누르기](ego-install-1.png)

화면에 **macOS** 단추와 **Windows (beta)** 단추가 나란히 있어요. **Windows (beta)** 를 **한 번** 누릅니다. 두 번 누르지 마세요. 받아지는 데 잠깐 걸릴 수 있어요.

- 화면에 맥(Mac) 컴퓨터 그림이 보여도 걱정 마세요. 단추만 **Windows**를 누르면 됩니다.
- 화면 오른쪽 위에 "표시 언어를 한국어로 변경할까요?" 같은 상자가 뜨면 **"한국어로 표시"** 를 눌러도 됩니다.
- 윈도우에서는 아직 **베타(시험판)** 라서 가끔 불편한 점이 있을 수 있어요.

## 4단계. 받은 파일 두 번 누르기

![받은 설치 파일 두 번 누르기](ego-install-3.png)

받은 설치 파일의 이름은 **egoliteSetup** 이고, 위 그림처럼 하얀 상자에 까만 동그라미가 그려진 모양이에요. 이 그림을 **마우스 왼쪽 단추로 빠르게 두 번** 누르세요.

- 파일은 보통 **'다운로드' 폴더**에 들어 있습니다. 인터넷 창에 나오는 다운로드 표시에서 눌러도 됩니다.
- 찾기 어려우면 키보드의 **윈도우 키**를 누르고 `다운로드` 라고 쓴 뒤 나오는 폴더를 누르세요. 그 안에서 **방금 받은 파일**(가장 위에 있는 것)을 두 번 누르면 됩니다.

## 5단계. 아무것도 안 눌러도 저절로 설치돼요

파일을 두 번 누르면 **별다른 화면 없이 저절로 설치가 시작되는 컴퓨터가 많아요.** 내가 누를 단추가 없으니, 그냥 **잠깐 기다리세요.** 설치가 끝나면 **에고 라이트가 저절로 열립니다.**

- 컴퓨터에 따라 **윈도우가 묻는 창**이 뜰 수도 있어요. 겁먹지 않으셔도 됩니다. 컴퓨터가 "이 파일 믿어도 되나요?" 하고 한 번 물어보는 창이에요. 내가 방금 **공식 사이트에서 직접 받은 파일**일 때만 아래처럼 하세요.
  - 파란 창에 **"Windows의 PC 보호"** (인식할 수 없는 앱의 시작을 차단했습니다) 라고 나오면: 글 가운데의 **"추가 정보"** 를 누르세요. 아래에 게시자(만든 곳)가 **CITRO LABS PTE. LIMITED** 라고 보이면 에고 라이트를 만든 곳이 맞아요. 그러면 나타나는 **"실행"** 단추를 누르세요.
  - **"이 앱이 디바이스를 변경하도록 허용하시겠습니까?"** 라고 나오면: **"예"** 를 한 번 누르세요.
- 이 창들은 보안 때문에 화면 캡처가 안 되어 그림은 싣지 않았습니다. 안 뜨면 그대로 기다리시면 돼요.

## 6단계. 에고 라이트가 열렸는지 확인하기

잠깐 기다리면 **에고 라이트 창이 열립니다.** 인터넷 창처럼 생긴 새 창이에요.

- 1~2분이 지나도 안 열리면: 키보드의 **윈도우 키**를 누르고 영어로 `ego` 라고 쓴 뒤, 나오는 것을 누르세요.

## 7단계. 처음 설정 — 화면이 여러 장 나와요

에고 라이트가 처음 열리면 **설정 화면이 여러 장 이어서** 나와요(8장쯤). 대부분 **"다음"** 같은 단추를 눌러 넘기면 되고, 가입이나 로그인은 필요 없어요. 화면 글자는 한국어로 나옵니다. (화면 순서와 이름은 버전과 컴퓨터에 따라 조금 달라요.)

중간에 **"데이터 가져오기"** 화면이 나와요. 지금 쓰는 인터넷 창(엣지·크롬)의 즐겨찾기와 **로그인 정보**를 에고 라이트로 옮겨 올지 묻는 화면입니다.

![처음 설정 화면에서 고르는 두 가지](ego-install-5.png)

(위 그림은 이해를 돕는 설명용이고, 실제 화면은 조금 달라요.)

**가져오기(A)를 고르세요.** 이미 로그인해 둔 사이트를 에고 라이트에서도 바로 쓸 수 있어서, 클로드에게 일을 시킬 때 매번 다시 로그인하지 않아도 돼요. 훨씬 편하고 쉽습니다.

1. 화면에 나온 **인터넷 창 목록**에서 **내가 평소 쓰는 것**(엣지 또는 크롬)에 **체크(✓)** 가 되어 있는지 보세요. 처음에는 **엣지만 체크**돼 있고 크롬은 빠져 있을 수 있어요. 크롬을 쓰시면 크롬에 체크하세요.
2. 프로필이 여러 개면 **평소 일하는 프로필**을 고르세요. 다른 프로필을 고르면 로그인이 안 돼 있어 보여요.
3. 가져올 내용(즐겨찾기, 로그인 정보 등)을 한 번 확인하고 **계속하는 단추**를 누르세요. 윈도우가 묻는 창이 뜨면 읽고 진행하세요.

- 원래 쓰던 인터넷 창은 **그대로 남아요.** 정보를 **복사**해 오는 것이라, 두 창은 이후에 서로 맞춰지지 않습니다.
- 가져오기 싫거나 건너뛰었다면(**"나중에 설정"**): 나중에 에고 라이트의 **설정 → 데이터 가져오기(Import data)** 에서 언제든 다시 가져올 수 있어요.

**그 밖의 화면은 이렇게 넘기세요.**

- **소식 구독, 설문** 같은 화면은 **내 마음대로** 하세요. 안 해도 쓰는 데 지장이 없어요.
- 마지막 쪽에 **"기본 브라우저 설정"** 이 나오면: 에고 라이트는 클로드가 쓰는 **전용 창**이니, 평소 쓰는 인터넷 창을 바꾸고 싶지 않으면 **기본으로 하지 않아도 됩니다.**
- 마지막 쪽에 **"작업 표시줄 고정"** 과 **"사용자 경험 프로그램 참여"** 에 체크돼 있을 수 있어요. 작업 표시줄 고정은 화면 맨 아래 줄에 에고 라이트 그림을 붙여 두는 것이라 있으면 편해요. **사용자 경험 프로그램 참여**는 사용 정보를 보내는 것이라, 원하지 않으면 체크를 빼세요.
- 가져온 뒤에는 에고 라이트에서 평소 쓰는 사이트를 하나 열어 **내 계정으로 로그인돼 있는지** 눈으로 확인해 보세요. 로그인이 안 돼 있으면 그 사이트에서 내가 직접 로그인하면 됩니다.
- 이 설정이 끝나야 **클로드와의 연결도 마무리**됩니다. 끝까지 해 주세요.

## 8단계. 클로드 앱 열고 Code 칸으로 가기

설치가 끝나면 에고 라이트가 클로드 쪽에 **"ego-browser"** 라는 기능을 자동으로 넣어 둡니다. 이제 눈으로 확인해 볼게요.

1. **클로드 앱을 여세요.** 에고 라이트 설치 때 클로드 앱이 켜져 있었다면, 앱을 한 번 **닫았다가 다시 여세요.** (창 오른쪽 위의 **X** 를 누르면 닫혀요.)
2. 앱 맨 위의 **Code(코드)** 를 한 번 누르세요.
3. **내 컴퓨터에서 하는 새 작업**(로컬 세션)을 시작하세요. 화면 모양은 앱 버전에 따라 조금 달라요.

- **Cowork(코워크)** 칸이 아니라 **Code(코드)** 칸이어야 합니다. Cowork 쪽에는 이 기능이 나타나지 않아요.

## 9단계. /ego 써서 연결 확인하기

![/ego 라고 쓰면 ego-browser 가 나타나요](ego-install-6.png)

글 쓰는 칸을 한 번 누르고, 키보드로 `/ego` 라고 쓰세요. (슬래시(/) 모양 글자 뒤에 영어 ego 입니다.) 쓰는 중에 아래에 **ego-browser** 가 나타나면 **연결된 거예요.**

- 안 나타나면 아래 「연결이 안 보일 때」를 순서대로 해 보세요.
- 지금 쓴 `/ego` 는 지우고 다음 단계로 가요. (키보드의 **Backspace(백스페이스)** 를 눌러 지워도 되고, 그대로 이어서 써도 됩니다.)

## 10단계. 첫 번째 시험해 보기

글 쓰는 칸에 아래 글을 그대로 쓰거나 붙여 넣고 키보드의 **Enter(엔터)** 를 한 번 누르세요.

`ego-browser로 https://example.com 을 에고 라이트에서 열어 줘. 실제 주소와 페이지 제목을 알려 줘. 다른 브라우저는 쓰지 마.`

- 클로드가 에고 라이트에서 사이트를 열고, **주소와 제목을 알려 주면 성공**입니다. 여기까지 되면 연결은 끝이에요. 수고하셨어요!
- 클로드가 "이 작업을 해도 될까요?" 하고 물으면, **무슨 일을 하려는지 읽고** 괜찮을 때만 허용하세요.
- 에고 라이트로 넘어가 보시면 클로드가 열어 둔 창을 볼 수 있어요. 클로드가 하는 일을 눈으로 확인할 수 있습니다.

## 연결이 안 보일 때 (ego-browser 가 안 나타나면)

위에서부터 순서대로 하나씩 해 보세요. 되면 거기서 멈추면 됩니다.

1. **클로드 앱을 완전히 껐다가 다시 켜세요.** 에고 라이트 설치 중에 클로드 앱이 켜져 있었다면 이것만으로 되는 경우가 많아요. (창 오른쪽 위 **X** 로 닫은 뒤, 다시 열어요.)
2. **Code(코드) 칸인지, 내 컴퓨터(로컬) 작업인지** 다시 보세요. Cowork 칸에서는 안 보여요.
3. **에고 라이트 처음 설정을 끝까지 마쳤는지** 보세요. 에고 라이트를 열어 처음 설정 화면이 남아 있으면 끝까지 진행하세요. 연결은 이 설정을 마칠 때 완성돼요.
4. **클로드에게 직접 물어보세요.** Code(코드) 칸의 글 쓰는 칸에 아래 글을 쓰고 엔터를 누르세요. 확인만 시키는 글이에요.

   `ego-browser 스킬이 이 컴퓨터에 설치돼 있는지 확인해 줘. 터미널에서 ego-browser skill 명령이 되는지도 알려 줘. 아무것도 바꾸지는 마.`

5. **ego-browser 설명서를 직접 넣어 보세요.** 에고 라이트 공식 안내에 있는 방법이에요. Code(코드) 칸의 글 쓰는 칸에 아래 글을 쓰고 엔터를 누르세요.

   `에고 라이트 공식 안내대로 ego-browser 스킬을 설치해 줘. 명령은 npx skills add citrolabs/ego-lite 이야.`

   - 클로드가 **"Node.js 가 없어서 안 된다"** 며 **Node.js를 설치할까요?** 하고 물을 수 있어요. 이 명령에 꼭 필요한 프로그램이라서 그래요. **무엇을 설치하려는지 읽어 보고** 괜찮으면 허용하세요. 마음에 안 들면 허용하지 말고 6번으로 가세요.
   - 끝나면 **클로드 앱을 껐다가 다시 열고** 9단계를 다시 해 보세요.
6. 그래도 안 되면 **설치 파일(egoliteSetup)을 한 번 더 두 번 눌러** 다시 설치한 뒤, 1번부터 다시 해 보세요.

## 지켜 주세요

- **비밀번호와 인증 번호는 클로드 대화창에 쓰지 마세요.** 로그인이 필요하면 에고 라이트 창에서 **내가 직접** 입력하세요. 입력한 뒤 "계속해 줘" 하고 말하면 됩니다.
- **결제, 삭제, 메일·메시지 보내기**처럼 되돌리기 어려운 일은 클로드에게 맡기기 전에 내가 한 번 더 확인하세요.

## 막힐 때는

- **9단계에서 `ego-browser`가 안 보이면:** 지금 **Code(코드)** 칸의 내 컴퓨터(로컬) 작업인지 확인하세요. 에고 라이트 설치가 끝났을 때 클로드 앱이 켜져 있었다면 **앱을 껐다가 다시** 열고 확인하세요.
- **클로드가 에고 라이트를 못 연다고 하면:** 에고 라이트가 **같은 컴퓨터**에 설치돼 있는지 확인하고, 클로드가 허락을 묻는 창이 떴는지 보세요. 허락 창이 있으면 읽고 진행한 뒤 다시 시켜 보세요.
- **시험 중에 로그인 화면이 나오면:** 에고 라이트 창에서 내가 직접 로그인한 뒤 클로드에게 "계속해 줘"라고 하세요.
- **"한도 초과", "인증 오류" 같은 글이 먼저 나오면:** 에고 라이트 문제가 아니라 클로드 계정·이용량 쪽 문제일 수 있어요. 클로드 사이트의 안내를 확인하세요.
- **설치 파일을 눌렀는데 아무 일도 없는 것 같으면:** 1~2분 기다려 보세요. 그래도 안 열리면 6단계처럼 윈도우 키로 `ego` 를 찾아 열어 보세요. 보안 안내가 나오면 5단계의 "추가 정보 → 실행"을 확인하세요.
- **어디서 막혔는지 모르겠으면:** 화면을 사진으로 찍어 두었다가 아티스트 코치 문의 게시판에 올려 주세요. (계정 이름이나 대화 목록이 보이면 가리고 올려 주세요.)
