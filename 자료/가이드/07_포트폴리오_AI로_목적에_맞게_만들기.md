# 예술인 포트폴리오, AI로 목적에 맞게 만드는 법 — 움직이는 HTML과 PDF, 제 포트폴리오도 공개해요

한 줄 요약: 포트폴리오는 제출처·목적·어필할 점부터 정하고, 제출처 레퍼런스를 조사한 뒤 AI와 함께 만들어요. 움직이는 HTML을 메인으로, PDF를 대비용으로 한 벌 더 만들어 두세요.

포트폴리오를 만들어야지 하면서도 막상 열어 보면 막막하셨죠? 어떤 활동을 넣을지, 사진은 어떻게 고를지, 어떤 순서로 보여 줄지... 게다가 남의 포트폴리오를 보면 다 멋있어 보이는데, 내 것은 어디서부터 손대야 할지 모르겠고요.

저는 이 고민을 AI와 함께 풀어서, 웹브라우저에서 열면 글자가 하나씩 나타나고 연표가 그려지는 12장짜리 움직이는 포트폴리오를 만들었어요. 그런데 오늘 하고 싶은 이야기는 '이렇게 똑같이 만드세요'가 아니에요. 포트폴리오는 어디에 내느냐에 따라 달라져야 하니까, 목적에 맞게 AI와 함께 만드는 방법을 알려 드릴게요. 제 포트폴리오는 그중 한 가지 예시로 보여 드릴게요.

## 먼저, 제 포트폴리오를 따라 할 필요는 없어요

포트폴리오에 정답은 없어요. 지원사업에 내는 포트폴리오, 레지던시 공모에 내는 포트폴리오, 공연이나 강의 섭외를 받으려고 보내는 포트폴리오는 보는 사람도, 보는 시간도, 궁금해하는 내용도 달라요.

- 심사위원은 짧은 시간에 많은 서류를 봐요. 그래서 핵심 실적이 앞에 나와야 해요.
- 섭외하는 사람은 '이 사람에게 맡기면 되겠다'는 믿음을 찾아요. 그래서 비슷한 규모의 작업 사례가 중요해요.
- 협업을 제안받는 사람은 '이 사람의 색깔'을 궁금해해요. 그래서 대표작과 작업 방향이 잘 보여야 해요.

그래서 이 글에서는 만드는 순서를 이렇게 잡을 거예요. 먼저 목적을 정하고, 제출처의 레퍼런스를 조사하고, 그에 맞게 구성을 짜고, 그다음에 만들어요.

## 1단계: 목적부터 정해요, 질문 세 가지

AI에게 만들어 달라고 하기 전에, 스스로 이 세 가지에 답해 보세요. 답이 정해지면 AI에게 훨씬 정확하게 부탁할 수 있어요.

- **어디에 내나요?** 지원사업, 레지던시, 공모전, 공연이나 강의 섭외, 협업 제안 같은 제출처를 구체적으로 정해요.
- **무엇을 이루려고 내나요?** 선정되기, 섭외받기, 협업 제안하기, 기관과 신뢰 쌓기 중 하나를 정해요.
- **무엇을 어필하나요?** 활동 기간, 대표작, 수상, 협업 경험, 교육 경력 중 가장 내세울 한두 가지를 정해요. 다 말하려고 하면 아무것도 기억에 남지 않아요.

같은 사람이라도 제출처가 다르면 포트폴리오가 달라져요. 목적이 여러 개라면, 하나를 기본으로 만들고 제출처마다 장면 순서와 분량만 바꾸는 방법도 있어요.

## 2단계: 제출처의 레퍼런스를 먼저 조사해요

내가 내려는 곳에서 어떤 형식의 포트폴리오를 받는지, 선정된 사람들은 어떻게 구성했는지 먼저 알아보세요. 이 조사를 AI에게 맡기면 훨씬 빨라요. 단, 조사 결과는 틀릴 수 있으니 출처를 꼭 확인하세요.

**프롬프트 1 · 제출처 레퍼런스 조사**

```
나는 [분야 예: 연극 연출가]이고, [제출처 예: OO문화재단 지원사업 공고]에 포트폴리오를 제출하려고 해. 1) 이 공고(또는 같은 종류의 공고)의 제출 서류 항목, 파일 형식, 분량과 용량 제한을 정리해 줘. 2) 같은 분야에서 포트폴리오를 낼 때 보통 어떤 구성과 분량으로 만드는지 공개된 사례를 찾아서 요약해 줘. 3) 심사하는 쪽이 중요하게 보는 항목이 무엇인지 공고문에 나온 심사 기준을 근거로 정리해 줘. 모든 내용에는 출처 링크를 붙이고, 확인하지 못한 내용은 '추정'이라고 표시해 줘. 지어내지 마.
```

공고문에 제출 형식(PDF만 받는지, 용량 제한이 몇 MB인지)이 나와 있다면 그게 가장 중요한 레퍼런스예요. 공고 원문을 AI에게 함께 보여 주세요.

## 3단계: 구성을 먼저 짜요

조사 결과와 1단계에서 정한 목적을 바탕으로 구성을 짜요. 바로 만들지 말고, 구성안을 먼저 보고 어떤 장을 넣고 뺄지 정하세요. 이 단계가 결과물의 품질을 좌우해요.

**프롬프트 2 · 목적에 맞는 구성안**

```
'포트폴리오_자료.md'(내 활동 정리 파일)와 위의 제출처 조사 결과를 바탕으로 포트폴리오 구성안을 짜 줘. 제출처는 [제출처], 이루려는 목적은 [예: 지원사업 선정], 가장 어필할 점은 [예: 최근 5년 대표작 3편]이야. 장마다 '제목 / 들어갈 내용 / 보여 줄 사진 / 한 줄 메시지'를 표로 보여 주고, 제출처의 분량과 형식 제한을 지킨 안으로 짜 줘. 어필할 점이 앞쪽에 오게 하고, 자료에 없는 내용은 지어내지 마.
```

자료 정리가 안 되어 있다면 코치 노트의 '내 예술활동 이력, AI와 함께 정리하는 법' 글을 먼저 보세요. '포트폴리오_자료.md'를 만드는 데 도움이 돼요.

## 4단계: 형식을 골라요, HTML이 메인, PDF가 대비책

- **HTML**: 모션그래픽을 넣을 수 있어서 가장 멋져요. 글자가 나타나고, 연표가 그려지고, 숫자가 올라가는 움직임으로 보는 사람의 시선을 잡아요. 파일 하나로 되고 웹브라우저로 열기만 하면 돼요. 소개 영상처럼 보여 주고 싶을 때 좋아요.
- **PDF**: HTML을 받지 않는 곳이 많기 때문에 꼭 같이 만들어 두세요. 공고에서 PDF만 받는다고 하거나 용량 제한이 있을 때, 또 이메일로 보내거나 인쇄할 때 쓰는 대비책이에요. HTML 장면을 한 페이지씩 담으면 돼요.
- **PPT**: 이것도 충분히 만들 수 있어요. 다만 클로드나 챗GPT 같은 AI는 제 경험으로는 PPT보다 HTML 파일을 더 잘 만들어요. 움직임도 훨씬 자연스럽고요. PPT가 꼭 필요한 곳에 내야 한다면 HTML로 먼저 만들고 PPT로 옮겨 달라고 하는 것도 방법이에요.

그래서 제 추천은 이거예요. HTML로 먼저 멋지게 만들고, 같은 내용을 PDF로 한 벌 더 만들어 두세요. 제출처에 따라 골라 쓰면 돼요.

**프롬프트 3 · 움직이는 HTML 포트폴리오 제작**

```
구성안대로 HTML 파일 하나로 1920x1080 크기의 슬라이드 포트폴리오를 만들어 줘. 장마다 글자가 차례로 나타나는 움직임을 넣고, 자동 재생과 클릭·방향키 이동, 전체화면(F키)을 지원해 줘. 사진은 파일 안에 포함해서 이 파일 하나만 있으면 어디서든 열리게 해 줘. 글자는 구성안에 있는 내용만 쓰고, 바꾸거나 덧붙이지 마.
```

**프롬프트 4 · PDF 대비본 만들기**

```
방금 만든 HTML 포트폴리오를 PDF로도 저장해 줘. 장면마다 한 페이지씩, 가로 1920x1080 크기로 하고, 움직임이 모두 끝난 완성 화면을 담아 줘. 조작 버튼과 진행 표시는 PDF에 나오지 않게 해 줘. 용량이 [제출처 용량 제한 예: 20MB] 안쪽이 되도록 사진 해상도를 조절하고, 마지막에 파일 크기를 알려 줘.
```

## 5단계: 모든 글자를 내 눈으로 점검해요

AI가 만든 완성본에는 날짜나 직함이 틀리게 들어갈 수 있어요. 글자를 한 번에 뽑아서 원본과 대조하세요. 이 단계는 건너뛰지 마세요.

**프롬프트 5 · 확인용 목록 만들기**

```
만든 포트폴리오 HTML에 들어간 모든 글자를 장면 순서대로 '확인용 목록.md'로 뽑아 줘. 날짜, 금액, 직함, 수상명이 들어간 줄에는 [확인] 표시를 붙여 줘. 파일의 내용은 고치지 마.
```

목록의 [확인] 줄을 상장, 확인서, 계약서 같은 원본과 하나씩 대조해서 틀린 곳은 AI에게 고쳐 달라고 부탁하세요. 고친 뒤에는 PDF도 다시 만드는 것을 잊지 마세요.

## 이럴 땐 어떻게 하죠?

- **어느 제출처에 낼지 아직 못 정했어요**: 우선 내가 가장 내고 싶은 곳 하나를 정하고 시작하세요. 나중에 다른 곳에 낼 때는 그곳의 조사를 새로 하고 장면의 순서와 분량만 바꾸면 돼요.
- **AI가 조사한 레퍼런스가 맞는지 모르겠어요**: 답변에 붙은 출처 링크를 열어서 공고문과 대조하세요. 링크가 없거나 열리지 않는 내용은 믿지 마세요.
- **용량이 너무 커요**: 사진 해상도가 높으면 PDF가 커져요. AI에게 용량 제한을 알려 주고 사진 크기를 줄여 달라고 하세요.
- **AI가 중간에 멈췄어요**: '계속해 줘'라고 보내거나, 새 대화에서 같은 프롬프트를 다시 보내 보세요.
- **움직임이 너무 빠르거나 느려요**: '연표 점이 찍히는 속도를 두 배 느리게 해 줘'처럼 숫자로 말하면 잘 고쳐 줘요.

## 놓치기 쉬운 것들

- 가장 중요한 건 사실 확인이에요. 날짜, 직함, 수상명, 숫자는 원본과 대조하세요.
- 포트폴리오는 바뀌어요. 활동이 늘 때마다 장면을 한 장씩 고쳐 두세요.
- 원본 HTML과 PDF는 백업해 두세요. 외장하드나 클라우드처럼 두 군데에 두면 좋아요.
- 공개용과 제출용을 나눠 두면 편해요. 홈페이지나 블로그에는 연락처를 빼고, 제출용에는 넣는 식으로요.

## 꼭 확인하세요

- AI 서비스의 기능과 요금은 시기와 요금제에 따라 달라질 수 있어요. 서비스의 공식 안내를 확인해 주세요.
- 제출처마다 파일 형식, 분량, 용량, 제출 방법이 달라요. 공고문의 제출 서류 안내를 꼭 확인하고, 그 규격에 맞춰 만들어 주세요.
- AI가 조사한 내용에는 틀리거나 오래된 정보가 섞일 수 있어요. 출처 링크를 열어 직접 확인해 주세요.
- AI가 날짜, 직함, 수상명을 잘못 쓰거나 지어낼 수 있어요. 완성본의 모든 숫자와 이름은 반드시 원본 증빙과 대조해 주세요.
- 포트폴리오에 넣는 연락처, 얼굴 사진, 함께한 사람들의 이름은 공개되는 정보예요. 공개해도 되는 범위인지 먼저 확인하고, 다른 사람이 나온 사진은 동의를 받아 주세요.

> **영감의 한마디**
> 포트폴리오는 나를 자랑하는 문서가 아니라, 보는 사람이 원하는 답을 내 이야기로 보여 주는 문서예요. 누구에게 낼지 정하면 무엇을 뺄지도 보여요. 도구는 AI가 쉽게 만들어 주지만, 무엇을 보여 줄지는 내가 정해야 해요. 영감이 응원할게요.
