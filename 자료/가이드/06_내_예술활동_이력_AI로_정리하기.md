# 내 예술활동 이력, AI와 함께 정리하는 법 — 폴더 하나와 엑셀 한 장이면 충분해요

한 줄 요약: 흩어진 공연 사진과 서류를 폴더 하나에 모아 두고, AI에게 '부탁 문장' 9개만 보내면 엑셀 표 한 장으로 정리돼요.

지원서를 열었는데 이력란 앞에서 손이 멈춘 적 있으세요? '작년 그 공연이 몇 월이었지?', '출연확인서는 어디에 뒀지?' 하면서 사진첩, 카톡, 메일함을 뒤지다 보면 어느새 밤이 깊어 있죠.

괜찮아요. 정리를 못해서 그런 게 아니에요. 활동하느라 바빴고, 아무도 정리하는 방법을 알려 주지 않았을 뿐이에요. 오늘은 컴퓨터가 서툴러도 따라 할 수 있게, 가장 쉬운 말로 알려 드릴게요.

## 이런 적 있으시죠?

- 지원서 쓰기 전날 밤, 공연 날짜와 장소를 카톡과 메일에서 다시 찾아본다
- 출연확인서, 계약서, 상장이 폴더에도, 서랍에도, 휴대폰에도 흩어져 있다
- 이력서 파일이 '최종', '진짜최종', '수정2'로 여러 개라 뭐가 최신인지 모르겠다
- 지원서마다 이력을 새로 쓰다 보니 매번 내용이 조금씩 다르다
- 활동은 많이 했는데 증빙이 없어서 인정받지 못할까 봐 걱정된다

하나라도 해당되면 이 글이 꼭 필요한 분이에요.

## 먼저, 전체 순서만 보세요

딱 5단계예요. 어렵게 느껴지면 그림만 보고 넘어가셔도 돼요.

![이력 정리 5단계: 모으기, 백업, 폴더 정리, 연혁표, 점검](ai-roadmap.svg)

| 항목 | 내용 |
|---|---|
| 이런 분께 | 활동 이력과 증빙이 흩어진 예술가 누구나 |
| 필요한 것 | 컴퓨터, 엑셀, 내 컴퓨터의 폴더를 직접 열어 정리해 주는 AI |
| 핵심 | 내 이름의 폴더 하나 + 엑셀 연혁표 한 장 |
| 꼭 지킬 것 | 신분증 같은 개인서류는 AI에게 보여 주지 않기 |

## 처음 보는 낱말, 미리 풀어 드릴게요

- **AI**: 말로 부탁하면 대신 일해 주는 컴퓨터 도우미예요. 챗GPT, 클로드 같은 것들이에요.
- **프롬프트**: AI에게 하는 '부탁 문장'이에요. 말을 거는 문장이라고 생각하면 돼요.
- **폴더**: 파일을 담아 두는 서랍이에요.
- **경로**: 폴더가 컴퓨터 어디에 있는지 알려 주는 주소예요.
- **엑셀**: 칸이 있는 표를 만드는 프로그램이에요.
- **연혁표**: 내가 한 활동을 날짜 순서로 적은 표예요.
- **증빙**: 내가 그 활동을 했다는 걸 보여 주는 서류예요. 출연확인서나 계약서 같은 거예요.
- **백업**: 혹시 몰라서 한 벌 더 복사해 두는 거예요.

## 내가 할 일은 딱 두 가지예요

1. 자료를 한 폴더에 넣어 두기
2. AI에게 부탁 문장 보내기

폴더 만들기, 파일 옮기기, 이름 바꾸기, 표 만들기는 AI가 해요. 사람에게는 정말 지치는 일이지만, AI는 이런 일을 제일 잘해요.

### AI에게 부탁하는 법은 세 번의 손짓이에요

이 글에는 복사해서 쓰는 '프롬프트 상자'가 모두 9개 나와요.

![복사, 붙여넣기, 보내기 세 단계](ai-prompt-howto.svg)

- 상자 안의 **[ ]** 로 된 부분은 내 내용으로 바꾸는 자리예요. 특히 **[폴더 경로]** 에는 내 자료를 넣어 둔 폴더의 주소를 적어요. (주소 알아내는 법은 1단계에서 알려 드려요.)
- AI 답이 마음에 안 들면 '더 쉽게 설명해 줘', '다시 해 줘'라고 이어서 말하면 돼요. 한 번에 완벽할 필요 없어요.
- 자주 쓰는 프롬프트는 메모장에 저장해 두세요.

### 어떤 AI를 쓰면 되나요?

내 컴퓨터의 폴더를 직접 열어서 파일을 읽고, 옮기고, 이름을 바꿔 주는 AI가 필요해요. 대표적으로 '클로드 코드', '챗GPT 워크' 같은 서비스가 이런 일을 해요. 쓰시는 AI가 폴더 작업을 할 수 있는지, 어떻게 폴더를 지정하는지는 서비스마다 달라요. 해당 서비스의 공식 안내를 꼭 확인해 주세요.

## 1단계: 자료를 한 폴더에 모아요

정리보다 먼저 할 일은 '모으기'예요. 이 단계를 건너뛰면 나중에 '그 파일이 또 어딨더라' 하게 돼요.

![여러 곳에 흩어진 자료를 내 예술활동 이력 폴더 하나로](ai-gather.svg)

아래 장소를 하나씩 떠올려 보세요.

- 휴대폰 사진첩과 카카오톡 보관함 (공연 사진, 포스터 사진, 받은 파일)
- 이메일에 붙어 온 파일 (출연확인서, 계약서, 선정 통보서)
- 네이버 MYBOX, 구글 드라이브 같은 인터넷 저장 공간
- 컴퓨터 바탕화면과 '다운로드' 폴더, 예전 컴퓨터, 외장하드
- 서랍 속 종이 서류, 팸플릿, 프로그램북, 상장 (휴대폰 스캔 앱으로 사진 대신 PDF로 만들어 두세요)
- 내 활동이 실린 기사나 SNS 글 (파일이 아니라 링크 주소만 모아 두면 돼요)

이렇게 따라 해 보세요.

1. 빈 곳에서 마우스 오른쪽 버튼을 눌러요. '새로 만들기 → 폴더'를 고르고, 이름을 '내 예술활동 이력'으로 적어요. 위치는 바탕화면이든 문서 폴더든 찾기 쉬운 곳이면 어디든 괜찮아요.
2. 모아 온 자료를 전부 그 폴더 안에 넣어요. 이름이 엉망이어도, 폴더 안에 폴더가 있어도 괜찮아요. 정리는 AI가 해 줘요.
3. 그 폴더의 주소(경로)를 복사해 두세요. 폴더를 열고, 맨 위 주소창을 한 번 눌러요. 글자가 파랗게 되면 키보드에서 Ctrl 키를 누른 채 C를 눌러요. 이게 복사예요. (예: D:\내 예술활동 이력)

> 예) 이 주소가 앞으로 프롬프트의 [폴더 경로] 자리에 들어가요.

이 단계가 끝나면: 내 활동 자료가 한 폴더 안에 다 모인 상태예요.

## 2단계: 한 벌 더 복사해 두어요 (백업)

본격적으로 정리하기 전에 폴더를 통째로 한 벌 더 만들어 두세요. AI가 혹시 실수해도 언제든 되돌릴 수 있는 안전장치예요. 이것도 AI에게 시키면 돼요.

![원본 폴더와 백업 폴더](ai-backup.svg)

**프롬프트 1 · 폴더 통째로 백업하기**

```
[폴더 경로] 폴더 전체를 같은 위치에 '내 예술활동 이력_백업'이라는 이름으로 통째로 복사해 줘. 원본 폴더는 절대 건드리지 마. 복사가 끝나면 파일 개수가 같은지 확인해서 알려 줘.
```

백업본은 정리가 다 끝난 뒤에도 한동안 지우지 마세요. 더 안전하게 하려면 외장하드나 인터넷 저장 공간에도 한 벌 더 넣어 두세요.

이 단계가 끝나면: 같은 자료가 두 군데에 있는 상태예요. 이제 마음 놓고 AI에게 맡겨도 돼요.

## 3단계: AI가 폴더를 정리해 줘요

지금 폴더가 엉망이어도 부끄러워하지 마세요. 대부분의 예술가분들이 그래요. AI가 이걸 아래처럼 바꿔 줄 거예요.

![번호가 붙은 폴더 7개와 연혁표 파일](ai-folder-tree.svg)

이제 AI에게 정리를 시켜 보세요. 폴더를 만드는 것도, 파일을 옮기는 것도 AI가 해요. 나는 문장만 보내면 돼요.

**프롬프트 2 · 자료를 전부 확인하고 폴더별로 정리하기**

```
내가 [폴더 경로] 폴더에 나의 예술활동 자료를 전부 넣어놨어. 그 안의 자료를 하나도 빠짐없이 모두 확인하고, 아래 7개 폴더를 만든 다음 각 자료를 어느 폴더에 두면 좋을지 직접 판단해서 옮겨 정리해 줘. 폴더: 01_내 정보(취급주의), 02_지원사업, 03_공연·전시 증빙, 04_사진·영상, 05_이력서·프로필, 06_수상·교육·자격, 07_정리 필요. 규칙: 1) 파일은 절대 삭제하지 마. 2) 신분증, 통장사본, 주민등록등본처럼 보이는 개인서류는 열어보지 말고 파일 이름만 보고 01_내 정보(취급주의)로 옮겨 줘. 3) 어디에 둘지 확실하지 않으면 07_정리 필요로 옮겨 줘. 4) 어떤 파일을 어디로 옮겼는지 '정리기록.txt'로 폴더 안에 남겨 줘. 5) 끝나면 폴더별 파일 개수를 요약해 줘.
```

AI가 일하는 동안에는 기다리기만 하면 돼요. 자료가 많으면 시간이 걸릴 수 있어요. 도중에 멈추면 '계속해 줘'라고 말해 주세요.

다음은 파일 이름이에요. 날짜와 내용을 이름에 넣어 두면, 이름순으로 줄 세우기만 해도 시간 순서대로 보여서 훨씬 편해요. 날짜도 내가 찾을 필요 없어요. AI가 파일을 열어서 직접 찾아 적어 줘요.

![240518_봄소리음악회_출연확인서처럼 날짜 6자리와 활동명과 서류 종류로 이름 붙이기](ai-file-name.svg)

**프롬프트 3 · 파일 이름을 [날짜 6자리]_[자료내용]으로 바꾸기**

```
[폴더 경로] 안의 01_내 정보(취급주의) 폴더를 제외한 모든 파일을 하나씩 열어서 확인하고, 파일 이름을 '[날짜 연월일 6자리]_[자료내용]' 형식으로 바꿔 줘. 날짜는 자료 안에 적힌 활동일(공연일, 전시일, 행사일)을 직접 찾아서 적어 줘. 활동일이 없는 서류는 발급일이나 작성일을 써 줘. 사진은 파일 정보에 있는 촬영 날짜를 써 줘. 자료내용은 활동명과 서류 종류가 드러나게 써 줘. 예: 240518_봄소리음악회_출연확인서.pdf. 날짜를 찾을 수 없는 파일은 이름 앞에 '000000_'을 붙이고 '정리기록.txt'에 따로 적어 줘. 파일 확장자(.pdf 등)는 그대로 둬.
```

마지막으로 폴더 안내문도 AI에게 만들어 달라고 하세요. 몇 달 뒤의 나도 바로 찾을 수 있어요.

**프롬프트 4 · 폴더 안내문 만들기**

```
[폴더 경로] 맨 위에 '읽어보세요_폴더 안내.txt' 파일을 직접 만들어 줘. 01~07번 폴더에 각각 어떤 자료가 있는지, 폴더별 파일 개수, 파일 이름 규칙('[날짜 연월일 6자리]_[자료내용]')을 누구나 이해할 수 있게 짧게 적어 줘.
```

AI가 끝났다면 내 눈으로 한 번 확인해 보세요. 폴더를 열어서 번호 폴더 7개가 보이는지, 파일 이름이 날짜 순서로 늘어서는지 보시면 돼요. 이상한 곳이 있으면 AI에게 '이 파일은 03번 폴더로 옮겨 줘'처럼 다시 부탁하면 돼요.

이 단계가 끝나면: 자료가 번호 폴더에 나뉘어 담기고, 파일 이름이 시간 순서로 정렬되는 상태예요. 여기까지 오셨다면 절반은 온 거예요!

## 4단계: AI가 엑셀 연혁표를 만들어 줘요

이 단계가 가장 중요해요. 연혁표는 엑셀 한 장에 **'한 활동 = 한 줄'** 로 적고, 그 활동을 보여 주는 증빙 파일 이름까지 같이 적는 표예요.

엑셀로 만드는 이유는 간단해요. 날짜순으로 줄 세우고, 필요한 것만 골라 볼 수 있고, 지원서에 붙일 때 복사해서 쓰기 쉬워서예요.

![엑셀 연혁표 예시와 아래쪽 시트 탭 5개](ai-sheet.svg)

엑셀 아래쪽에 탭이 5개 있어요. 이걸 '시트'라고 불러요. 시트마다 담는 내용이 달라요.

| 시트 | 들어가는 것 |
|---|---|
| 연혁표 | 공연, 전시, 교육 등 모든 활동 (날짜, 활동명, 유형, 장소·주최, 역할, 증빙 파일, 확인) |
| 수상·선정 | 상을 받았거나 지원사업에 뽑힌 내역 |
| 교육·자격 | 수료증, 자격증 |
| 활동 수입 | 활동으로 받은 돈과 입금일 (예술활동 수입 증빙에 큰 도움이 돼요) |
| 링크 | 기사, 영상, SNS 글 주소 |

**프롬프트 5 · 연혁표.xlsx 만들기**

```
[폴더 경로] 안의 모든 자료(01_내 정보(취급주의) 제외)를 확인해서 '연혁표.xlsx' 파일을 이 폴더 맨 위에 직접 만들어 줘. 시트는 '연혁표', '수상·선정', '교육·자격', '활동 수입', '링크' 5개야. '연혁표' 시트의 열은 '날짜 / 활동명 / 유형 / 장소·주최 / 역할 / 증빙 파일 이름 / 확인'이야. 한 활동당 한 줄로 쓰고 날짜가 빠른 순서로 정렬해 줘. 유형은 공연, 전시, 교육, 지원, 수상 중에서 골라 줘. 증빙 파일 이름에는 폴더 안의 실제 파일 이름을 적어 줘. 확인 열은 기본으로 '확인필요'라고 적고, 증빙 파일이 없는 활동은 증빙 칸을 비워 두고 확인 열에 '빈칸'이라고 적어 줘. 자료에 없는 내용은 절대 지어내지 마. 수상·선정, 교육·자격, 링크 시트도 같은 방식으로 채워 줘.
```

활동으로 받은 돈도 따로 적어 두면 좋아요. 아래 프롬프트로 '활동 수입' 시트를 채워 보세요. (꼭 안 해도 돼요.)

**프롬프트 6 · 활동 수입 시트 채우기 (선택)**

```
[폴더 경로]의 '연혁표.xlsx' 파일에 있는 '활동 수입' 시트를 채워 줘. 폴더 안의 계약서, 입금내역, 정산서류를 확인해서 활동으로 받은 돈만 '입금일 / 활동명 / 금액(원) / 지급처 / 증빙 파일 이름' 열로 적어 줘. 모르는 칸은 지어내지 말고 비워 둬.
```

AI가 끝났다면 '연혁표.xlsx'를 열어 보세요. 엑셀 아래쪽에 시트 탭이 5개 보이면 잘 만들어진 거예요.

이 단계가 끝나면: 내 활동이 표 한 장으로 정리된 상태예요.

## 5단계: 빈칸과 틀린 곳을 점검해요

표를 만들었다면 이제 점검할 차례예요. 사람이 놓치기 쉬운 곳을 AI가 먼저 훑어 줘요.

**프롬프트 7 · 연혁표 점검하기**

```
[폴더 경로]의 '연혁표.xlsx'를 열어서 점검해 줘. 1) 증빙 파일 칸이 비었거나 '확인필요'인 줄 2) 날짜가 같거나 활동명이 거의 같은 중복 줄 3) 날짜 형식이 다르거나 연도가 이상한 줄 4) 증빙 파일 이름이 폴더에 실제로 없는 줄. 결과는 같은 파일에 '점검결과' 시트를 새로 만들어서 적어 줘. 기존 시트의 내용은 고치지 마.
```

그리고 가장 중요한 마지막 점검은 **내 눈**이에요. 표의 '확인' 칸이 그걸 도와줘요.

![확인 칸 사용법: 확인필요에서 완료로, 증빙이 없으면 빈칸으로 두고 확인서 요청](ai-check.svg)

1. 엑셀에서 '점검결과' 시트를 열고, 알려 준 줄의 증빙 파일을 열어서 날짜와 활동명이 맞는지 확인해요.
2. 틀린 곳은 엑셀에서 직접 고치거나, AI에게 '이 줄의 날짜를 이렇게 고쳐 줘'라고 부탁해요.
3. 맞게 확인한 줄은 '확인' 칸을 '완료'로 바꿔요.
4. '빈칸'으로 남은 활동은 지금 담당 기관에 확인서를 요청해 두세요. 나중에 큰 도움이 돼요.

이 단계가 끝나면: 믿고 쓸 수 있는 나만의 활동 이력표가 완성된 상태예요. 정말 수고하셨어요!

## 정리해 두면 이렇게 써요

- **지원서 이력란**: 연혁표에서 필요한 활동만 뽑아 바로 붙여넣어요.
- **소개서와 프로필**: 연혁표를 바탕으로 짧은 소개문과 긴 소개문을 만들어요.
- **예술활동증명 준비**: 증빙 파일 이름을 따라가면 제출할 자료를 한 번에 모을 수 있어요.
- **지원사업 이력 관리**: 지원한 사업, 결과, 정산 보고서 마감일까지 한 시트에 적어 두면 놓치지 않아요.

**프롬프트 8 · 지원서에 붙일 이력 만들기**

```
[폴더 경로]의 '연혁표.xlsx'에서 최근 5년 안의 [공연] 활동만 골라서, '연도. 활동명 (장소·주최, 역할)' 형식으로 지원서에 붙일 이력을 써 줘. 연혁표에 없는 내용은 절대 덧붙이지 마. 결과는 대화창에 보여 주고, 05_이력서·프로필 폴더에 '이력 초안.txt'로도 저장해 줘.
```

## 정리는 한 번이 아니라 습관이에요

처음 정리가 끝났다면 유지하는 건 쉬워요. 활동이 끝난 날 딱 3가지만 하세요.

1. 증빙 파일을 '내 예술활동 이력' 폴더에 넣기
2. 공연·전시 사진도 같은 폴더에 넣기
3. 아래 프롬프트를 보내서 연혁표에 한 줄 추가하기

새로 들어온 파일의 폴더 정리와 이름 바꾸기는 프롬프트 2와 3을 다시 보내면 AI가 해 줘요.

**프롬프트 9 · 새 활동을 연혁표에 추가하기**

```
[폴더 경로]의 '연혁표.xlsx'에 새 활동을 한 줄 추가해 줘. 활동 내용: [날짜, 활동명, 장소, 내 역할]. 관련 증빙 파일이 폴더 안에 있으면 찾아서 증빙 파일 칸에 적어 주고, 없으면 비워 두고 확인 열에 '빈칸'이라고 적어 줘.
```

## 이럴 땐 어떻게 하죠?

- **한글(hwp) 파일을 AI가 못 읽어요**: 한글에서 '다른 이름으로 저장'을 눌러 PDF로 저장한 뒤 다시 시도해 보세요.
- **AI가 엉뚱한 날짜를 적었어요**: 원본 증빙을 열어서 직접 고치거나 AI에게 고쳐 달라고 하세요. '확인' 칸은 내가 확인한 뒤에 '완료'로 바꿔요.
- **AI가 중간에 멈췄어요**: '계속해 줘'라고 보내 보세요. 그래도 안 되면 새 대화를 열고 같은 프롬프트를 다시 보내면 돼요. 이미 정리된 부분은 건너뛰고 이어서 해 줘요.
- **폴더 경로를 AI가 못 찾아요**: 폴더 주소창에서 복사한 주소를 그대로 붙여넣었는지, 쓰시는 AI에서 작업할 폴더를 지정했는지 확인해 보세요.
- **증빙이 아예 없어요**: 연혁표에는 적어 두고 '확인' 칸을 '빈칸'으로 남겨 두세요. 그리고 주최 측에 확인서를 요청해 보세요.
- **AI가 파일을 열거나 바꿔도 되냐고 물어봐요**: 파일을 읽거나 바꾸기 전에 허락을 받는 안전장치예요. 내 자료 폴더 안의 일이라면 허용해 주세요. 다른 폴더를 건드리려고 하면 허용하지 마세요.
- **정리가 잘못된 것 같아요**: 2단계에서 만든 백업 폴더에서 원본을 꺼내 다시 시작하면 돼요.

## 놓치기 쉬운 것들

- AI가 정리해 준 날짜, 활동명, 금액은 틀릴 수 있어요. 꼭 원본과 맞춰 보세요.
- 여럿이 함께한 작업은 내 역할(출연, 연출, 작곡, 기획 등)을 정확히 적어 두세요.
- 증빙이 없는 활동은 지금이라도 주최 측에 확인서를 요청해 두세요. 시간이 갈수록 어려워져요.
- 공연 사진에는 관객과 출연자의 얼굴이 나와요. SNS나 홍보물에 쓸 때는 초상권을 꼭 확인하세요.
- 백업은 두 군데에 해 두세요. 예를 들어 내 컴퓨터와 외장하드, 또는 인터넷 저장 공간에요.

## 개인정보는 꼭 지켜 주세요

예술가의 자료에는 신분증, 통장사본, 주민등록등본처럼 민감한 서류가 섞여 있어요. 가장 안전한 방법은 이런 서류를 처음부터 이 폴더에 넣지 않고 따로 보관하는 거예요. 이미 넣었다면 프롬프트 2의 규칙대로 AI가 열어보지 않고 01번 폴더로만 옮기게 해 주세요.

AI가 읽은 파일은 그 서비스를 통해 처리돼요. 내 대화가 AI 학습에 쓰이는지는 서비스 설정에서 확인하고, 원하지 않으면 꺼 두세요. 함께 활동하는 단원이나 동료의 서류는 그분들의 개인정보이기도 해요. 본인 동의 없이 이 폴더에 넣지 않는 것이 안전해요.

## 꼭 확인하세요

- AI 서비스의 기능과 요금, 한 번에 올릴 수 있는 파일 수는 시기와 요금제에 따라 달라질 수 있어요. 서비스의 공식 안내를 확인해 주세요.
- AI가 날짜나 활동명을 잘못 읽거나 지어낼 수 있어요. 연혁표는 반드시 내가 원본 증빙과 맞춰 보세요.
- 신분증, 통장사본, 주민등록등본 같은 개인서류는 AI에 올리거나 보여 주지 마세요.
